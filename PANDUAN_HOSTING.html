5Langkah 2 — Buat repository

Repository (repo) = folder proyek di GitHub.

  1. Di halaman utama GitHub, klik tombol + kanan atas → New repository
  2. Repository name: ketik portfolio
    Harus persis portfolio — huruf kecil semua — supaya alamatnya rapi.
  3. Description: Portofolio Electrical Engineer — Wildan Rizky Safa Pratama
  4. Pilih Public
    Wajib Public. Kalau Private, GitHub Pages berbayar.
  5. Jangan centang "Add a README file" — biarkan kosong
  6. Klik Create repository

6Langkah 3 — Pasang GitHub Desktop

Aplikasi ini membuat upload jadi semudah menyalin folder — dan bisa menangani file besar.

  1. Buka desktop.github.com → klik Download for Windows
  2. Jalankan installer → tunggu selesai → buka GitHub Desktop
  3. Klik Sign in to GitHub.com → masuk dengan akun yang baru dibuat
  4. Setelah masuk, pilih menu File → Clone repository → tab GitHub.com → pilih username/portfolio → Clone
  5. Tentukan lokasi penyimpanan lokal, misal:
    D:/PORTFOLIO KARIR/_github/portfolio
  6. Klik Clone — folder kosong akan dibuat
Apa yang baru saja terjadi GitHub Desktop membuat folder kosong di komputer yang terhubung ke repository di GitHub. Setiap kali kamu mengubah isi folder itu lalu klik "Commit" + "Push", perubahannya terkirim ke GitHub.

7Langkah 4 — Salin file website

  1. Buka folder sumber di File Explorer:
    D:/PORTFOLIO KARIR/06_Website
  2. Pilih semua isinya (Ctrl+A) — bukan foldernya, tapi file dan folder di dalamnya
  3. Copy (Ctrl+C), lalu buka folder hasil clone tadi (D:/PORTFOLIO KARIR/_github/portfolio) → Paste (Ctrl+V)

8Langkah 5 — Commit & Push

  1. Buka GitHub Desktop. Di panel kiri akan muncul ratusan file baru dengan tanda centang hijau.
  2. Di pojok kiri bawah, isi kolom Summary:
    Website portofolio awal
  3. Klik tombol biru Commit to main
  4. Klik Push origin di bar atas
    Proses upload ± 130 MB — bisa 3–10 menit tergantung koneksi. Jangan tutup aplikasi.
Tanda berhasil Setelah selesai, buka halaman repository di github.com. Semua file harus terlihat di sana. Kalau index.html terlihat, lanjut ke langkah berikutnya.

9Langkah 6 — Aktifkan GitHub Pages

Ini momen website benar-benar jadi.

  1. Di halaman repository, klik tab Settings (ikon gerigi, paling kanan)
  2. Di sidebar kiri, gulir ke bawah → klik Pages
  3. Bagian Source → pilih Deploy from a branch
  4. Bagian Branch:
    • dropdown pertama: pilih main
    • dropdown kedua: biarkan / (root)
  5. Klik Save
  6. Tunggu 1–3 menit. Refresh halaman Settings → Pages.
    Akan muncul tulisan: "Your site is live at ..."

Alamat website-mu

https://USERNAME.github.io/portfolio/

Ganti USERNAME dengan username GitHub yang kamu pilih di Langkah 1.

10Langkah 7 — Periksa hasilnya

Buka alamat itu di browser. Periksa satu per satu:

  • Halaman utama tampil dengan foto profil di navigasi dan nama lengkap
  • Gambar-gambar muncul (tidak ada kotak rusak)
  • Tombol CV → Lihat CV membuka cv.html
  • Tombol Unduh PDF mengunduh file CV
  • Section Dokumen → Sertifikat menampilkan gambar sertifikat FASI
  • Video bisa diputar (mungkin agak lambat di awal — normal)
  • Buka di HP juga — pastikan tampilannya rapi
Kalau gambar tidak muncul Penyebab paling umum: struktur folder salah. Cek apakah assets/img/ ada sejajar dengan index.html, bukan di dalam subfolder lain.
Kalau muncul error 404 Tunggu 3–5 menit lagi — GitHub butuh waktu membangun situs pertama kali. Kalau masih 404 setelah 10 menit, cek lagi: repository harus Public, dan Branch harus main dengan folder / (root).

12Cara update website nanti

Setiap kali ada perubahan (proyek baru, foto baru, CV diperbarui):

  1. Edit file di folder D:/PORTFOLIO KARIR/06_Website
  2. Salin ulang file yang berubah ke folder _github/portfolio
  3. Buka GitHub Desktop → isi Summary → Commit to main → Push origin
  4. Tunggu 1–2 menit → refresh website → perubahan muncul
Tips Lebih praktis kalau kamu langsung bekerja di folder _github/portfolio setelah setup awal. Jadi tidak perlu salin-salin lagi. Folder asli 06_Website bisa dijadikan cadangan.

14Masalah yang sering muncul

GejalaPenyebab & solusi
Halaman 404 setelah aktifkan Pages Belum selesai build. Tunggu 3–5 menit. Kalau tetap: pastikan repo Public dan Branch = main, folder / (root).
Website tampil tapi tanpa gambar Struktur folder salah. index.html harus sejajar dengan folder assets/, bukan di dalam subfolder.
Halaman putih kosong Mungkin ada index.html ganda. Pastikan hanya satu, di root.
Upload gagal / stuck di 2 video Batas 25 MB per file saat upload lewat browser. Pakai GitHub Desktop (Langkah 3).
Video tidak mau diputar File terlalu besar untuk koneksi, atau belum selesai terunggah. Cek ukuran file di repo.
Perubahan tidak muncul Sudah commit tapi belum Push. Atau cache browser — coba Ctrl+Shift+R.
Repository Private tidak bisa Pages GitHub Pages untuk repo Private butuh akun Pro. Ubah repo jadi Public di Settings.
